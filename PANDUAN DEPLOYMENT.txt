# Panduan Deployment FS-WebTopup (Storefront)

Panduan deployment resmi sistem Feryshop dapat dilihat pada dokumentasi terpadu:
- **Panduan Deployment Lengkap:** `docs/PANDUAN_DEPLOYMENT.md`
- **Docker Compose Orkestrasi:** `docker-compose.prod.yml`
- **Container Registry:** `ghcr.io/feryshop-cloud/fs-webtopup:latest`

Untuk menjalankan kontainer storefront secara mandiri:
```bash
docker run -d \
  --name fs-webtopup \
  --restart unless-stopped \
  -p 8080:8080 \
  --env-file .env.local \
  ghcr.io/feryshop-cloud/fs-webtopup:latest
```
